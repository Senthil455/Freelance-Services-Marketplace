# SkillForge static prototype

A static prototype built with plain HTML, CSS and JavaScript to practice the skills learned in January and February.

Features:
- gigs data stored in a javascript array (data.js)
- category filter buttons
- live search with the / shortcut
- sorting by price or rating
- a gig detail page reading the id from the url

This is not a real backend. The real app comes next with Node and Express. Built March 2025.
